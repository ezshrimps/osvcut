# osvcut studio 使用指南

## 启动

```bash
python server.py 8360 "E:\Videos"
```

浏览器打开 `http://localhost:8360/viewer/`。第一次启动会扫描素材文件夹（239 段约 20 秒），并在后台逐张生成拼接好的全景缩略图。

环境要求：Python 3.10+、带 CUDA 的 PyTorch、opencv-python、numpy、faster-whisper（语音转写，可选），以及 PATH 里支持 `h264_nvenc` 的 ffmpeg/ffprobe。

## 四个页面

| 页面 | 用途 |
|---|---|
| **素材库** | 所有 OSV 按活动分组；搜索框也会搜**台词**（先点「转写全部素材」，约十几分钟，之后输入一句话就能定位到片段和时间）。缩略图是已经拼接、校平的全景图，鼠标悬停会横向平移。可以搜索、按分类筛选、按时间或时长排序。标签含义：`8K`、`可播放`（已有高质量预览）、`实时`（已有实时预览代理）、`已编辑`（有保存的剪辑）、`无音频` |
| **360° 查看** | 打开片段：自动生成实时预览代理。转码完成（约片长的 1/4–1/3）就能先用简单接缝实时播放，接缝分析在后台继续，完成后自动换成与导出一致的光流拼缝。拖动转视角，滚轮缩放 |
| **成片 & 任务** | 剪辑台（多段拼成一部片）、后台任务进度、导出的成片 |
| **拼缝盲测** | 两种拼缝算法的同位置特写，左右随机，选哪边更自然。数据用于论文的主观评价。「视频」模式是第二轮：光流拼缝和切缝各渲染一段 3 秒循环视频（同步播放），看接缝在运动中是否闪烁、扭动；后台会预先生成下一组 |

## 360° 查看里的操作

| 操作 | 方式 |
|---|---|
| 转视角 / 缩放 | 拖动画面 / 滚轮 |
| 播放、暂停 | `空格` |
| 前后跳 1 秒 / 逐帧 | `←` `→` / `,` `.` |
| 记录关键帧 | `K`（时间线上可以拖动关键帧，右键删除） |
| 入点 / 出点 / 清除 | `I` / `O` / `X` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），覆盖关键帧和入出点，最多 100 步 |
| 跟随主体 | 按住 `Shift` 在画面上拖框框住一个人，自动跟踪并生成关键帧 |
| 高清截图 | `P` 或「📷 高清截图」：当前时刻、当前视角，用完整光流拼缝渲染 4K 静帧（长边 3840，按所选画幅；调色和补地一并生效），约 2–3 秒后自动下载。「推荐片段」里的 📷 是每段稳定画面中最稳的一刻（转动和抖动最小、最不糊），点一下定位并暂停 |
| 拼缝对比 | `B`：实时预览在「光流形变」（与导出一致）和「仅切割」之间切换；示例片段则是新 / 旧拼缝 |
| 视角预设 | 标准、广角、超广角、水晶球、小行星、仰望天空 |
| 运镜模板 | 小行星开场、环绕一周、抬头揭幕、**跟拍持杆人**（入出点之间镜头始终对着拿自拍杆的人，只用 IMU 计算） |
| 看向持杆人 | 视角区的按钮，一键转向拿相机的人，作为取景起点 |
| 经纬网格 | 检查地平线是否水平（橙色是地平线，青色是正前方） |
| 显示接缝 | 红线是当前拼缝的位置，黄色是只有一个镜头看得到的区域（持杆人那一侧重叠最窄），方便检查拼接质量 |
| 调色 | 视角区的「调色」：曝光、对比度、饱和度、色温，以及一键预设（鲜艳、暖调、冷调、电影感、黑白）；实时预览里看到的就是导出效果（spec 里的 `grade`） |

**时间线**：橙色曲线是相机转动速度，红色刻度是晃动，青色条是有人说话，白色三角是关键帧，绿色区域是入出点范围，底部灰色是音频波形（方便对着说话、音乐或环境声找剪辑点），顶部紫色带是接缝难度（两镜头视差越大颜色越深；超过 1° 说明有近处物体，接缝可能看得出来，取景时尽量别让主体正好落在接缝上）。鼠标悬停可看具体数值和台词。

**右侧面板**：
- 语音转写：点任意一句跳过去；
- 建议片段：对话段、稳定画面（适合风景）、快速转动（适合转场），点一下自动设好入出点；
- 全景地图：黄框是当前画面的覆盖范围，点击跳转。

## 导出

1. 设好入出点和关键帧（手动、跟随主体或运镜模板都可以）；
2. 选一个「平台预设」（抖音 / 小红书 / 视频号竖屏、YouTube / B 站横屏、Instagram 4:5、方形、YouTube 360° / VR），会自动设好画幅、帧率和画质；也可以自己选输出画幅（16:9 / 9:16 / 1:1）、拼缝算法（默认"光流对齐"）、画质、帧率和速度（100fps 素材做 0.25× 慢动作不丢帧）；
3. 点「导出成片」；或点「＋ 剪辑台」，再到「成片 & 任务」里把多段拼成一部片。

**导出 360° 全景视频**：导出类型选「360° 全景视频」，用 `I` / `O` 设好入出点，导出的是校平后的完整全景（3840×1920，光流拼缝），自带球面元数据，可以直接上传 YouTube 或在 VR 头显里播放。「脚下补丁」可以选小 / 中 / 大（半径 10° / 15° / 20°），用脚下一圈地面的颜色平滑盖住手、自拍杆和影子，做小行星效果时尤其有用。

**全部导出 360°**：素材库每个分组标题旁的「🌐 全部导出 360°」，把这一组每段素材都导出为校平后的 360° 全景视频（3840×1920，光流拼缝，带球面元数据），任务排队依次完成。

**一键成片**：素材库每个分组标题旁的「✨ 一键成片」，输入目标时长、选横竖屏，就会从这一组里自动挑出说话片段（镜头对着持杆人、配字幕）和稳定的风景片段（缓慢横摇），加淡入淡出转场，导出一部短片；如果剪辑台选了背景音乐也会一起用上，并自动**卡点**：检测音乐的节拍，每段长度取整到两拍的倍数，让转场正好落在拍点上，音乐从第一拍开始。结果是初稿，可以再在剪辑台里调整。

**片头标题**：在「成片标题」或剪辑台的「整片标题」里写好标题，勾选旁边的「片头显示」，导出时会在开头 3 秒居中显示这个标题（淡入淡出）。

**局部慢放**：导出区的「局部慢放」——把播放头停在精彩瞬间的开头，导出时从这里起 1–2 秒放慢到 0.25× 或 0.5×，前后保持原速；声音同步变速（音调不变）。100fps 素材慢放不会重复帧。不能和整段变速或定格环绕同时使用。

**超级慢动作（光流插帧）**：速度选 0.125× / 0.0625×，或局部慢放选 0.125×。放慢到超过素材本身帧率时（例如 100fps 素材放慢 8 倍），中间帧由光流插帧合成，不再重复同一帧，画面不会一卡一卡。实测插出的帧比直接叠化清晰约 4–5 dB；渲染会比普通慢放慢 2–3 倍。

**定格环绕（子弹时间）**：导出区的「定格环绕」——把播放头停在想定格的那一刻，导出时画面会在这里停住 2–3 秒，镜头在定格的全景里转一圈（或半圈），然后继续播放；定格期间是静音，前后的声音保持对齐。不能和变速同时使用。

**字幕**：导出区的「字幕」可以把这段的语音转写烧进画面，或作为软字幕轨道（同时生成 .srt 文件）；变速时字幕时间会自动换算。

**保存 / 打开工程**：剪辑台的「保存工程」把各段（入出点、关键帧、导出设置）、转场和背景音乐设置存成一个 `.osvcut.json` 文件，换电脑或换浏览器后用「打开工程」恢复；素材库里找不到的素材会提示。

**剪辑台转场**：在「成片 & 任务」→ 剪辑台里选择转场（直接切 / 淡入淡出 / 黑场过渡 / 擦除 / 圆形展开）和时长；选了转场的整片会重新编码，直接切则无损拼接。

**剪辑台背景音乐**：在「成片 & 任务」→ 剪辑台里选择音乐文件，分别调节音乐和原声音量；导出整片时音乐会自动循环或截断到片长，并在结尾淡出。

导出由服务器在 GPU 上完成，使用完整的光流对齐拼缝（比实时预览的拼缝更好），结果在「成片 & 任务」里可以直接播放和下载。

## 给 AI / 脚本用

所有功能都能通过 JSON 和 HTTP 调用：

```bash
python osvcut.py my_cut.json                 # spec -> mp4
python sheet.py clip.OSV 6 sheet.jpg         # 给 AI 看的全景概览图
python track.py track_job.json               # 跟随主体 -> 关键帧
```

接口：`/api/library`、`/api/clip/<id>/motion`、`/api/clip/<id>/transcript`、`/api/jobs`（`kind`: preview / proxy / export / sequence）、`/api/track`。spec 字段说明见 README。

## 让 AI 助手直接剪辑（MCP）

工作台运行时，执行下面的命令把 osvcut 接入 Claude Code（或其他支持 MCP 的 AI 助手）：

```bash
claude mcp add osvcut -- python <osvcut 目录>/mcp_server.py
```

然后就可以直接说"在夏威夷那批素材里找朋友们走路聊天的片段，剪一个 30 秒的竖屏，开头用小行星"。AI 会依次搜素材、看概览、在关键时刻"转头看一眼"确认方向、跟随主体，最后导出。

AI 能用的工具：

| 工具 | 作用 |
|---|---|
| `list_clips` / `search_speech` | 列出素材（带台词摘要）/ 按说过的话搜索片段 |
| `clip_overview` | 一段素材的校平全景缩略图、语音转写、运动曲线和建议片段 |
| `look` | 在任意时刻、任意方向渲染一张画面（`at="holder"` 直接看向持杆人） |
| `holder_keys` / `track_subject` | 对准持杆人的关键帧 / 跟踪画面里的某个人 |
| `render_cut` | 导出一段：画幅、帧率、整段变速、局部慢放（`slow_from/slow_to/slow_speed`）、定格环绕（`freeze_at/freeze_seconds/freeze_turn`）、字幕（`captions`）、调色（`grade`）、脚下补丁（`nadir_patch`），或 360° 全景（`projection="360"`） |
| `render_sequence` | 多段拼成一部片，可加转场（`transition`） |
| `auto_edit` | 一键成片：给几段素材和目标时长，自动选段、取景、加转场和字幕 |
| `job_status` | 查询或等待导出任务 |

例如："把夏威夷那组素材一键剪成 30 秒竖屏"，或者"这段第 12 秒那个跳水的瞬间做个定格环绕"，或者"把跳水那 2 秒慢放"。（同一段里，局部慢放、定格环绕、整段变速三者只能选一个。）
