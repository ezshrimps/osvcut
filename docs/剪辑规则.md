# 一键成片的剪辑规则（director.py）

一键成片（工作台「一键成片」、MCP `auto_edit` / `plan_edit`）按下面这些规则出片。规则来自 360 素材的手工重构剪辑教程和旅拍 vlog 的常见做法，见文末来源。教程大多只给定性建议，具体数字（视场角、速度、时长）是我们按这批素材调出来的，写在括号里。

## 先理解，再取景（导演分镜，`directed_edit`）

一段素材值得剪进片子，是因为它在讲一件事：谁在说话，说的是什么，大家在看什么。全自动的一键成片只能猜“画面里哪里细节多”，猜不出这些。所以工具分成两层：

1. **理解（人或者 AI 助手来做）**：读完全部转写，按时间把素材串成一个故事（出发 → 第一个晚上 → 目的地 → 高潮 → 收尾），再看每个关键时刻的全景图（`clip_overview` 带方位刻度和红色接缝线，`look` 看单个方向），找出每段的主体：正在说话的人，话里提到的东西（说到要去哪里，就在画面里找那个地方；说到吃的，就对准那盘菜），大家一起看的东西，舞台。
2. **手艺（工具来做）**：把分镜表交给 `directed_edit`（MCP），每个镜头写 clip_id、起止时间、类型（talk / calm）、主体方向 focus {yaw, pitch}、可选的运镜（pan / push / pull / tilt / hold）、章节（换章节用甩镜）和一句备注。工具负责：
   - 对白镜头以 focus 指定的人作为初始锁定，只有别人明显在说话时才切过去；
   - 风景镜头对准 focus 做一个运镜；
   - 避开接缝；
   - 字幕、甩镜、小行星开头结尾、黑场。

一键成片（`auto_edit`）仍然保留，适合没时间理解素材的时候，但它只是猜测。

## 接缝：不用从截图猜，直接算出来

两颗镜头在机身坐标系里背对背（主镜头 +Y，副镜头 −Y），拼接引擎就在两者之间的平面 y = 0 上接缝（流光接缝在 ±4.5° 的带内微调）。每一帧的 IMU 姿态都是已知的，所以任何画面、任何时刻接缝的确切位置都能直接算出来：`director.seam_angle` 算任一方向到接缝的角距离，`seam_share` 算一个取景里接缝占多少（画面中心的权重是边缘的 3 倍）。相机竖着拿时，接缝是全景里两条竖线（在两颗镜头的侧面）；镜头正前方和正后方各有一大片干净区域。

规则：每个镜头都可以整体转一点，风景最多 30°，有指定主体的最多 15°，对白最多 12°，同时上下可以动 ±6°，转到接缝占比最小的位置（转得越少越好）。**如果接缝正好穿过画面中心的主体，就不动**：这段要拍的就是那里，接缝只能保留。

## 取景

- **风景镜头要看着东西**：先渲染一张拉平的全景小图，算每个方向的细节（边缘）、亮度和饱和度，压低天空、地面和持杆人身体方向的权重，然后对准最"有内容"的 70° 扇区，俯仰取该扇区的兴趣重心（限制在 −20°…+25°）。以前是一律朝机身正前方。
- **对白镜头对着说话的人**：先用 IMU 算出自拍杆方向，向上抬 58° 作为初始猜测，视场角从 1.08× 慢慢推到 1.0× 标准视场角。
- **人脸检测（YuNet）**：每 0.8 s 取一张 130° 的广角图找脸，取景方向是上一次锁定的脸；还没锁定时，用 IMU 猜测方向，并且前几次会把另外三个方向也看一遍。关键帧直接用人脸方向，让视线落在画面中心偏上约 12% 视高的位置，脸太大时把视场角放宽，保证头和肩都在画面里。某个时刻没检测到脸，就借用离它最近的那次检测结果去校正 IMU 猜测；一半以上的采样都没有脸时，整段只用 IMU。模型文件放在 `models/`，不进仓库，下载方法见 README。
- **导演指定的人优先**：分镜里给了 focus 的对白镜头，先锁定离 focus 最近的脸。
- **多人同框时找正在说话的人**：画面里有几张脸时，多渲染前后各 0.12 s 的两帧，比较嘴部区域和眼部区域的帧间变化（嘴动 ÷ 眼动；头和相机的晃动会让两个区域一起变化，说话只会让嘴变化）。只有另一个人的嘴动比当前锁定的人高 1.6 倍以上、绝对值超过 1.3，并且连续两次采样都是这样，才切换过去，避免镜头在人之间来回跳。谁都没在明显说话时，就留在当前的人身上；还没锁定任何人时，选离拿杆人最近的那张脸。
- **视场角按画质定**：4K 模式的素材每个镜头只有约 9 像素/度。1920 宽的画面用 84° 相当于放大 2 倍，会糊，所以横屏用 105°、竖屏用 80°，放大大约 1.3 倍；推近和拉远只在 0.92×–1.1× 之间变化。教程建议用窄视角拍脸和细节，但这批素材的分辨率撑不起窄视角，只能往宽了取。

## 运镜

- **一个镜头只做一个有目的的动作**，用缓入缓出（smoothstep）：
  - 横摇（pan）：扫过主体，最快 8°/s，方向朝兴趣更高的一侧；
  - 推近（push）：视场角 1.1× → 0.92×；
  - 拉远（pull）：上面反过来；
  - 抬头揭示（tilt）：主体在地平线上方时（高楼、舞台）从下往上抬。
- **相邻两个镜头不用同一种动作**。教程列出的常见错误包括：短镜头里关键帧太多、没理由地一直转、画面太广没有重点。

## 节奏

- **对白按整句剪**：第一个字前留 0.15 s，最后一个字后留 0.35 s，单段最长 8 s，不在句子中间切断。
- **风景镜头长度轮换**（3.5 / 3.0 / 4.5 / 3.0 / 4.0 s），不再每段都是 6.0 s。
- 有背景音乐时仍对齐节拍（`beats.py`）。

## 转场（transition = "auto"，默认）

- **同一场景内硬切**，每个切点有 30 ms 音频淡入淡出，避免爆音。
- **换天或换时段时用甩镜（whip pan）**：上一个镜头最后 0.35 s 加速转 80°，下一个镜头从反方向转进来、减速停住。教程里常见的旋转转场就是这个做法：两段素材的旋转方向和速度保持一致。
- **小行星开场**：第一个镜头从小行星视角旋转着展开到正常取景（2.6 s 展开，3.4 s 落定）。
- **小行星收尾**：最后一个镜头收回成小行星，整片最后 1 s 淡出到黑场。
- **小行星只用在开头和结尾**：教程提醒不要频繁使用，用多了会让人晕。
- 旧的淡入淡出、黑场、擦除转场仍然可以选。
